# My Mini Portfolio

A modern, responsive personal portfolio website for Teamr Yheys. It presents a background in full-stack web and mobile development, cybersecurity interests, selected projects, certifications, and social links.

## Features

- Editorial, dark-themed visual design
- Responsive layout for desktop, tablet, and mobile
- Sticky navigation with section links
- Animated hero, cards, project rows, and certification sections
- Scroll progress indicator
- Desktop contextual cursor interaction
- Keyboard focus states and reduced-motion support
- Existing project, social, and asset links preserved

## Project Structure

```text
my_mini_portfolio/
├── index.html
├── style.css
├── README.md
└── assets/
    ├── My_profile.jpg
    ├── professional-foundations-certificate.png
    └── alx-ai-starter-kit-certificate.png
```

## Run Locally

No framework or package installation is required. Open `index.html` directly in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Customization

- Update portfolio text and links in `index.html`.
- Adjust colors, layout, typography, and animations in `style.css`.
- Replace images inside the `assets` folder while keeping the referenced filenames, or update their paths in `index.html`.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
